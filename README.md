# Оплата контракта — студенты кампуса

Сайт для просмотра и отметки оплаты контрактов студентов.

- **Публичная страница** — список студентов, поиск, фильтры по семестру, группе и статусу. Только просмотр.
- **Вход для администрации** (декан, менеджер, администратор) — отметка оплаты одной кнопкой, добавление и редактирование студентов.

## Как устроено

`index.html` (GitHub Pages) → Google Apps Script (`apps-script-Code.gs`) → Google Таблица «Оплата студентов».

Данные студентов в репозитории **не хранятся** — только в Google Таблице.
Логины и пароли создаются в таблице: меню **«Сайт оплат»**.

Адрес API задаётся в начале скрипта в `index.html` (константа `API`).
